## Спільний контекст продукту

Рішення, ухвалені 2026-11-17. Діють для всіх специфікацій, доки окремий spec явно не змінить їх (зі записом у Changelog).

### Продукт
- Десктоп-застосунок, що живе у фоні й поверх ігор та інших програм допомагає з перекладом і вимовою.
- **MVP — лише перекладач.** Словник вивченого, тренування, інтервальне повторення — **v2**.
- Безкоштовний, open source на GitHub, ліцензія **MIT**. Без монетизації та власного сервера.

### Платформа і стек
- **Electron + TypeScript + React.**
- **MVP — лише Windows.** Код кросплатформний: ОС-специфічне (OCR, захоплення, дозволи) — за інтерфейсами. macOS — окремим spec після MVP.

### Безпека для ігор (жорсткі обмеження)
- Overlay — окреме прозоре вікно always-on-top. **Жодних DLL-ін'єкцій, читання пам'яті, hook-ів у графічний конвеєр гри, емуляції вводу.**
- Захоплення екрана — лише системні API (`desktopCapturer` / Windows Graphics Capture).
- Гарячі клавіші — лише `globalShortcut` (RegisterHotKey), без низькорівневих keyboard hook-ів.
- Підтримуються **віконний і borderless** режими ігор. Exclusive fullscreen — не підтримується (показуємо підказку).
- Якщо гра блокує захоплення (чорний кадр) — зрозуміле повідомлення користувачу.
- Overlay **click-through**: не перехоплює мишу/клавіатуру й не забирає фокус без явної дії користувача.

### AI
- **BYOK**: користувач вводить власний ключ. Провайдери MVP: **Anthropic** і **OpenAI-сумісний** (поле Base URL → OpenAI, OpenRouter, Groq, Ollama, LM Studio).
- Ключі — через Electron `safeStorage`. Налаштування — локальний JSON. Історія перекладів — лише в пам'яті сесії (персистентність — v2).
- Лічильник токенів (сесія / весь час) і орієнтовна вартість за редагованою таблицею цін; для локальних моделей вартість не показується.

### Екран і переклад
- Режими: **переклад області за запитом** і **зона слідкування** (знімок ~700 мс → піксельний diff → OCR → текстовий diff → LLM; ліміт 20 запитів/хв за замовчуванням). Постійний аналіз усього екрана — не робимо.
- OCR — **локально**: Windows OCR основний, Tesseract.js запасний. На LLM іде текст, картинка — лише за явним запитом.
- Відображення етапу 1: **плашка з перекладом біля області + віконце з розбором**. Точне накладання поверх оригіналу з перемиканням клавішею — етап 2.
- Контекст для LLM: останні ~10 реплік + необов'язкове поле «що я зараз граю».
- Мульти-монітор і DPI-масштабування — з MVP.

### Голос
- Push-to-talk. STT: **whisper.cpp локально** (за замовчуванням), OpenAI опційно.
- TTS: **голоси ОС** (за замовчуванням), OpenAI TTS опційно.
- «Повтори фразу» — порівняння розпізнаного тексту з очікуваним. Справжня оцінка вимови — v2.
